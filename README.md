# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用（无需构建）。

## 文件分层

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构与样式，不含业务逻辑 |
| `js/rules.js` | 规则层（纯逻辑）：工序流转门禁、返工、缺陷记录、旧数据迁移、建单 |
| `js/storage.js` | 存储层：localStorage 读写、种子数据、加载时迁移、JSON 导出 |
| `js/app.js` | 页面层：渲染、表单、筛选、详情对话框、事件编排 |

## 工序流转规则

工序固定为 **贴线中 → 待阴干 → 上金粉 → 待交付**：

- 只能逐道**顺序推进**，不能跳工序；新增作品一律从「贴线中」进入。
- 停在「待阴干」时，若阴干日期晚于今天，只能继续等待，不能推进。
- 进入「上金粉」前必须**没有待修复缺陷**；推进时金粉状态自动置为「已上金粉」。
- 进入「待交付」时贴线进度自动记为 100%。
- **返工**只能退回上一道工序，且必须填写原因，原因写入流转记录。

不满足条件时「推进」按钮禁用并显示原因（卡片上有红字提示，详情中有完整门禁说明）。

## 缺陷管理

- 缺陷为结构化记录，状态为「待修复 / 已修复」。
- 可在卡片或详情中记录缺陷、标记修复；修复可附修复说明。
- 修复后记录与全部流转日志**永久保留**，不删除历史。
- 旧版 `defect` 文字字段在加载时自动拆分为多条「待修复」记录（支持 `;`、`；`、换行分隔），迁移幂等，不产生重复数据。

## 其他功能

- 新增作品（胎体、纹样、线条、进度、阴干/交付日期、金粉状态、初始缺陷、备注）。
- 看板四列展示；阴干到期、待修复缺陷、最近交付三个摘要列表。
- 主题筛选、状态筛选、按交付/阴干日期排序。
- 作品详情：门禁状态、缺陷历史、完整流转记录。
- localStorage 持久化（键 `zfl42Works`），一键导出 JSON。
